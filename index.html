Projects

A group project for a real client in Calamba. It covers the problem, what we built, how, and what I learned.

iLooc: Barangay Information System

A system for Barangay Looc, Calamba City that handles resident information, document requests, and the borrowing of barangay items.

Software Engineering 2 Research
Visit iLooc Website ↗
PROBLEM
Barangay services like document requests and item borrowing needed one place where they could be recorded and monitored.
BUILT
Five modules: user authentication, resident information, document requests, request monitoring, and borrowing and service management. Users get in-app notifications.
HOW
Modeled the system with a hierarchy chart, use cases, and data flow diagrams with five data stores (D1 to D5), all drawn in draw.io. Wrote the full research paper with the group.
LEARNED
I learned that a system like this can make the work at the barangay easier, because requests, records, and borrowing can be handled in one place instead of by hand. It also showed me how much clear design and well-organized data matter when building a system for real users.
